# NYC Public Schools SAT Performance Analysis

This project analyzes SAT performance across New York City public schools using Python and Pandas.

## Project Goals
- Identify schools with the best math results
- Find the top 10 schools based on total SAT scores
- Determine which borough has the largest variation in SAT performance

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Dataset
The dataset contains SAT results from NYC public schools.

## Files
- notebook.ipynb → Data analysis notebook
- schools.csv → Dataset used for the analysis
